# Angelina-Stepanova-and-Erdman
Датасет переписки писателя-драматурга Николая Эрдмана и его возлюбленной Ангелиной Степановой, актрисы МХАТа.

Текст очищен от воспоминаний А. О. Степановой и прочих нерелевантных заметок. Составлен алгоритм поиска адресанта, основанный на используемых обращениях. Найдены все даты, кроме использования только числа (2 телеграммы без месяца). В случае отсутствия даты, указывалось None. Даты приведены к формату YYYY-MM-DD при помощи регулярных выражений. Если год не указывался, он восстанавливался относительно ближайших месяцев. Письма были разделены по предложениям, что упростило поиск непосредственно текстов писем с помощью ключевых слов. Есть колонка с лемматизированным текстом, в котором удалены стоп-слова. В итоге вышло 43 письма от Николая и 31 от Ангелины. Результаты сохранены в CSV файл.
